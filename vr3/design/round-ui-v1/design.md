# Round UI concept

Three visual mockups generated with built-in image_gen over the longer lab night scene. These are design references, not baked runtime UI assets.

## Round 1 introduction

Small eyebrow: ROUND 1

Title: Contain the Inbox

Subtitle: 18 emails incoming

Large central countdown: 3 → 2 → 1 → GO

Give the title and subtitle about 1.5 seconds to read, then count down once per second. The thin mint ring drains around each numeral. Show GO briefly, fade the entire introduction out, then release the first email. Keep the background steady. No bouncing or camera movement.

## Round 2 introduction

Small eyebrow: ROUND 2

Title: Responding

Subtitle: You have 3 emails to handle

Use the same countdown and placement. Keep Responding consistent across levels so the task change is immediately clear. If there are zero replies, skip this round; use singular wording for one email.

## During round 1

One small upper-center translucent pill: envelope icon, 7 / 18, and a quiet CLEARED label. A thin mint line below shows the same progress. Count completed email actions, not spawned emails. Begin at 0 / 18; advance once per resolved email. The denominator stays fixed for that round.

Keep the flight path and central interaction zone free. No persistent title, countdown, score, timer, or celebratory animation. Smoothly fill the line over about 200 milliseconds; leave the pill's size and position stable. Use a dark translucent backing so the same display also reads in the daytime office.

The upper position in these flat panoramas is an art-direction sketch. In-headset UI should sit comfortably above the forward interaction area rather than at the extreme top of the headset view. Keep UI separate from the panorama and test text size and placement in the headset.
